Nixfied commands (model-generated)

Core apps:
  build - Build artifacts
  check - Run quality checks
  check-ports - Check model-derived port availability
  ci - Run the CI pipeline
  dev - Start the dev workflow
  format - Format Nix files
  framework::install - Install thin wrapper flake
  framework::test - Run framework validation in the model
  health - Run service health checks
  ports - Print model-derived port assignments
  ready - Run service readiness checks
  test - Run tests
  test-isolation - Run isolation checks
  validate-env - Validate slot/env settings

Dispatcher:
  run-task <task-id> [-- ...]
  run-workflow <workflow-id> [-- ...]
  run-workflow-parallel <workflow-id> [-- ...]

Workflows:
  workflow.ci.app - App CI workflow
  workflow.ci.basic - Basic CI workflow
  workflow.ci.env - Environment CI workflow
  workflow.ci.full - Full CI workflow
  workflow.test.parallel.failfast - Parallel runner fail-fast workflow
  workflow.test.parallel.smoke - Parallel runner smoke workflow
