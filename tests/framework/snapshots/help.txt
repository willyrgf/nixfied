Nixfied Project commands (model-generated)
Reusable Nix development framework

Core apps:
  build - Build artifacts
  check - Run quality checks
  check-ports - Check model-derived port availability
  ci - Run the CI pipeline
  dev - Start the dev workflow
  format - Format Nix files
  framework::install - Install thin or vendored wrapper flake
  framework::test - Run framework validation in the model
  framework::upgrade - Upgrade vendored wrapper in-place
  health - Run service health checks
  ports - Print model-derived port assignments
  ready - Run service readiness checks
  services-export - Export the default service set contract
  services-start - Start the default service set
  services-status - Show status for the default service set
  services-stop - Stop the default service set
  svcset::default::export - Default service set export
  svcset::default::health - Default service set health
  svcset::default::ready - Default service set ready
  svcset::default::start - Default service set start
  svcset::default::status - Default service set status
  svcset::default::stop - Default service set stop
  test - Run tests
  test-isolation - Run isolation checks
  validate-env - Validate slot/env settings

Introspection:
  introspect - Query compiled apps, tasks, workflows, services, and packages
  docs - Render detailed model documentation
  features - List compiled feature inventory
  schema - Print bundled export schemas
  stateHash - Print canonical model hash

Dispatcher:
  run-task <task-id> [-- ...]
  run-workflow <workflow-id> [-- ...]
  run-workflow-parallel <workflow-id> [-- ...]
  runs [run-id]
  stop-run <run-id>
  stop-all-runs

Workflows:
  workflow.ci.app - App CI workflow
  workflow.ci.basic - Basic CI workflow
  workflow.ci.env - Environment CI workflow
  workflow.ci.full - Full CI workflow
  workflow.test.framework.selfhost - Framework self-host smoke workflow
  workflow.test.isolation.probe - Isolation probe workflow
  workflow.test.parallel.failfast - Parallel runner fail-fast workflow
  workflow.test.parallel.smoke - Parallel runner smoke workflow
