## nixfied\.services\.\<name>\.endpoint



Single-endpoint sugar: the one tcp loopback endpoint the service binds\.

addressable\.

${host:\<endpointId>}\. Set ` primaryEndpoint ` to name the primary\.



*Type:*
attribute set of (submodule)



*Default:*
